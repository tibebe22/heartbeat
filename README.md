#Codes for analysis framework for higher-order temporal correlations with applications to heartbeats.

Author: Tibebe Birhanu (tibebebirhanu@gmail.com) and Hang-Hyun Jo (h2jo23@gmail.com)

Updated date: 6 November 2025

These codes developed for the research paper "Analysis framework for higher-order temporal
correlations with applications to human heartbeats."

This repository includes implementation and tools used to analyze the heartbeat timeseries datasets.

File.folder description
1. /header: header files including all function for the analysis
2. /run: execution files

main.c: main c file

run.sh: shell script for compiling and running the program

timings_example.txt: a sample heartbeat time series.
